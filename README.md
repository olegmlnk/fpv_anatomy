# Анатомія FPV-дрона

Інтерактивна 3D-сторінка про будову 5″ FPV-квадрокоптера: 12 вузлів з описами й видами компонентів, анімації моторів, польотного контролера та приймача, а також конфігуратор, який перераховує масу, тягу, струм і час польоту при заміні компонентів.

![Анатомія FPV-дрона: анімація Props In](docs/preview.jpg)

## Можливості

- **3D-модель з 12 вузлів.** Рама, мотори, пропелери, ESC 4-in-1, польотний контролер, приймач, відеопередавач і його антена, камера, акумулятор, XT60 з конденсатором, GPS. Усе змодельовано процедурно в коді, без зовнішніх 3D-файлів.
- **Взаємодія.** Наведення підсвічує вузол і показує підказку з виноскою. Клік наближає камеру до вузла й робить решту моделі прозорою. Подвійний клік (на телефоні подвійний тап) відкриває бічну панель: визначення, види, ключові параметри, заміна компонента.
- **Анімації.**
  - Мотори: Props In, Props Out і тест 1→2→3→4 за нумерацією Betaflight, газ регулюється повзунком.
  - Польотний контролер: кнопка BOOT, підключення USB, режим DFU, прошивка з прогресом.
  - Приймач ExpressLRS: немає зв'язку, біндинг, зв'язок, Wi-Fi — з реальними патернами світлодіода.
- **Конфігуратор.** 12 слотів із варіантами: KV моторів, пропелери, ESC, MCU, антени приймача, аналогові й цифрові VTX, LiPo та Li-ion. Оцінка злітної маси, тяги/ваги, пікового струму, часу польоту й попередження про несумісні комбінації.
- **Режими перегляду.** Розбирання на нумеровані вузли, потоки сигналів (живлення, CRSF, DShot, відео), тур по вузлах.
- Світла й темна тема за налаштуваннями системи, адаптивна верстка від 390 px.

## Запуск

Збирати нічого не треба: відкрийте `index.html` у браузері. Three.js і шрифти завантажуються з CDN, тому потрібен інтернет.

Локальний сервер (необов'язково):

```bash
npm start
```

GitHub Pages: Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`. Для приватного репозиторію Pages доступні лише на платних планах GitHub.

## Структура

```
index.html          розмітка сторінки
css/styles.css      стилі й токени світлої та темної теми
js/data.js          контент вузлів, варіанти конфігуратора, розрахунок характеристик
js/scene.js         рендерер, процедурні текстури й 3D-моделі вузлів
js/interaction.js   камера, вибір і підсвітка, розбирання, сигнали, анімації, головний цикл
js/ui.js            специфікація, конфігуратор, бічна панель, обробники подій
tests/smoke.js      smoke-тест на Playwright
docs/preview.jpg    знімок для README
```

Скрипти класичні (не ES-модулі) і ділять глобальну область видимості, тому сторінка відкривається навіть з `file://`. Порядок підключення в `index.html` важливий: `data.js → scene.js → interaction.js → ui.js`.

## Технології

- **Three.js r128 (WebGL):** PBR-матеріали, карта середовища з `PMREMGenerator`, процедурна геометрія (`Shape`, `ExtrudeGeometry`, `TubeGeometry`), `Raycaster` для вибору вузлів.
- **JavaScript (ES2020)** без фреймворку й без збірки. Власний orbit-контролер на Pointer Events.
- **CSS:** custom properties для тем, Grid, `position: sticky`, `dvh`, safe-area insets.
- **Canvas 2D** для текстур (карбон, маркування чипів і батарей, мат із міліметровою сіткою), **SVG** для схеми напрямів обертання та виносок.

## Як додати варіант компонента

1. Додайте об'єкт у відповідний масив `OPTS` у `js/data.js` (маса, KV, крок пропелера тощо).
2. Якщо варіант має виглядати інакше, змініть builder вузла в `js/scene.js` (`buildMotors`, `buildRX`, `buildVTX`…).
3. Якщо заміна впливає на інші вузли, допишіть залежність у мапу `DEPENDS` у `js/scene.js`.

## Тести

```bash
npm install
npx playwright install chromium
npm test
```

Тест відкриває сторінку на десктопній і мобільній ширині, проходить усі анімації та варіанти конфігуратора, відкриває бічну панель і перевіряє помилки в консолі та горизонтальне прокручування. Скриншоти зберігаються в `tests/shots/`. `three@0.128.0` у devDependencies потрібен, щоб тест не залежав від CDN.

## Обмеження

- Маса, тяга, струм і час польоту — інженерні оцінки за спрощеною моделлю для типових компонентів свого класу, а не паспортні дані конкретних моделей.
- Анімація світлодіода приймача відтворює логіку ExpressLRS; у TBS Crossfire індикація інша, тому Wi-Fi-режим для нього вимкнено.
- Three.js r128 підключено як UMD-збірку з cdnjs. Новіші версії Three.js поширюються лише як ES-модулі; для подальшого розвитку варто перейти на них разом із бандлером (наприклад, Vite).
- ~250 окремих мешів без інстансингу: для слабких телефонів першим кроком оптимізації буде `InstancedMesh` і злиття геометрій.
